# Integral-Approximation-NumPy
Utvecklade ett Python-program med NumPy och Matplotlib för att beräkna bestämda integraler med Riemannsumma och trapezregeln. Genomförde jämförelse mellan metoderna genom relativ felanalys och grafisk visualisering, samt tillämpade teoretiska felgränser för att bestämma lämpligt antal delintervall.

# Numerical Integration in Python

A Python project implementing polynomial antiderivatives, exact integration of polynomials, Riemann sums, the trapezoidal rule, relative error analysis, and numerical approximation of \(\int_0^2 e^{-x^2}\,dx\). Built using NumPy and Matplotlib.

Detailed:
Innehåll:
- Primitiv funktion till polynom
- Bestämd integral av polynom
- Numerisk integration med Riemannsumma
- Numerisk integration med trapezregeln
- Felanalys för jämförelse mellan metoderna
- Approximation av integralen \int_0^2 e^{-x^2} dx

Programmet är skrivet i Python och använder NumPy samt Matplotlib.
